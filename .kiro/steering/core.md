# Core (always on)

Learn: the Courses app of 84000.digital. Teachers' recorded lessons for Khmer-speaking students on phones. Local-first, no login, no server state. Scope detail: `product.md`.

## Protected behaviours (full text, files, contract tests: `protected.md`)
RULE: if a task would change a P-line, STOP, change nothing, report the line. Only a prompt saying `change protected: P-xx` may change it, and that commit updates `protected.md` AND its contract test.
- P-01 Loader verifies SHA-256 against the manifest before any store write; any failure keeps old data.
- P-02 A 200 is never proof a file exists; manifest shape + SHA-256 are the only gates.
- P-03 Manifest and data URLs are origin-absolute (`/data/...`, `?h=<sha256>`).
- P-04 Language: `?lang=km|en` then cookie `lang_84000` then `km`; cookie access in try/catch.
- P-05 `lang_84000` cookie: Domain `.84000.digital` only on that host, Path=/, 1 year, SameSite=Lax, Secure on https.
- P-06 Service worker `registerType: 'prompt'`; never a silent version switch.
- P-07 Real-path routing (History API); route list, legacy params, topic chips and partner routes as in `protected.md`.
- P-08 Lesson URL uses the lesson id, not the num.
- P-09 Tab bar Home, Search, My Learning, More; course/lesson/teacher/partner map to Home.
- P-10 Continue row only with history; Start here row from `paths.json` `start-here`, else hidden.
- P-11 Course page: progress, Start/Continue, ticks, sections of 20, find box, Save, Share. Partner class pages exempt.
- P-12 Own r2 audio player: resume, speed, +-15 s, sleep timer, autoplay, 90% done, Media Session, mini player. URL = `MEDIA_BASE_URL` + encoded key.
- P-13 Progress saved only after resume-seek applied and while playing.
- P-14 Own lessons play R2 only (audio; video if approved and switch on). Only KillerPlayer iframe on partner class pages after a tap. No download.
- P-15 My Learning tabs and Export/Import backup; Import rejects `app` not `learn-app`.
- P-16 Search strips U+200B from query and text, substring match, original shown; no result gives Vacana/Library links.
- P-17 Titles and names displayed exactly as stored (HTML-escaped only); empty title shows `no title`.
- P-18 No scripture text anywhere.
- P-19 Per-lesson release: shown only with APPROVED media in `media-manifest.json`; id guard; link change keeps old media live; partner-class rules.
- P-20 Clean cut at IndexedDB v3: keep only c080 and mapped lessons; nothing points at another course.
- P-21 Guide line shows only if `approved` is true; else nothing (DRAFT only in dev with `?guide=draft`).
- P-22 Sign chosen from data (`course_signs`, `default_sign`); bad file name falls back.
- P-23 Leaf added once per finished, non-ongoing course; never deleted or updated.
- P-24 Branch panel on `/my`: no numbers, levels, percent, comparison, empty slots.
- P-25 Start here reads only `paths.json`; people edit `data/`, never `public/data/`.
- P-26 No guilt: no notifications, streaks, points, ranks, loss wording, time fade.
- P-27 Bud = class started, no leaf yet; leaves first, then buds.
- P-28 Start here leaf mark: Start here row only, leaf sign only, no text.
- P-29 Only source of courses/lessons is the master sheet export (`data/master/*.csv`).

## Stack (as in this repo)
- Vite 8 + TypeScript 7, no UI framework; Tailwind v4 CSS-first via `@tailwindcss/vite` (no tailwind.config); `vite-plugin-pwa` generateSW, `registerType: 'prompt'`, `cleanupOutdatedCaches`, `clientsClaim`, `cacheId learn-<hash>`; `idb` for IndexedDB `learn-app`.
- Tests: Vitest 5 (`pool: 'forks'`, `maxWorkers: 2`, keep the pin), fake-indexeddb, jsdom; Playwright e2e through `npm run e2e`.
- Hosting: Cloudflare Worker `learn-app`, static assets only, `workers_dev: false`, custom domain `learn.84000.digital` in `wrangler.jsonc`. Never run a real `wrangler deploy` or `login`; only `npx wrangler deploy --dry-run`.
- Media in R2 (`media.84000.digital`), never in the repo. External base URLs live in `src/config.ts`, never derived from `location`.
- Data: `data/` and `data/source/` are inputs; `public/data/` is generated by `scripts/`. Never hand-edit generated files.
- Brand: `#7F0204` on `#EDE3C8`, panel `#F6EFDD`, line `#C9B896`, muted `#6B5D48`, leaf orange `#F26000` graphics only; content width <= 760 px.

## Commit and test rules
- `main` only. No branches or PRs unless asked. One commit per part.
- `npm test` and `npm run e2e` must both pass before push. A bug fix gets a new test (red then green). Never edit, skip or weaken an existing test.
- Commit only files inside the task's area (`scope-guard.md`). Restore out-of-scope files by exact path. Never `git reset`, `git clean`, `git checkout .`.
- Ask before force push, deletes, history rewrites. Never commit `data/source/` or `*-report.md` unasked.
- `change protected: P-xx` is the only way to alter a P-line.

## Never
- Never invent ids, slugs, titles, names, numbers, paths, versions or scripture. Unknown means "unknown" and ask.
- Never type, correct or reformat Khmer/Pali titles or teacher names; copy byte-for-byte. Tests use placeholders.
- No placeholder or sample courses, no TTS audio, no login, no downloads in v1.
